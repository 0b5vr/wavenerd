# CONTRIBUTING.md

### Icons

I use [`unplugin-icons`](https://github.com/antfu/unplugin-icons), [mdi icon set](https://icones.js.org/collection/mdi)

### How to deploy

To deploy, simply push to the `release` branch.
The `pages` job in the GitHub Actions will automatically deploy when a commit is pushed to the `release` branch.

See: [.github/workflows/inspect.yml](./.github/workflows/inspect.yml)
